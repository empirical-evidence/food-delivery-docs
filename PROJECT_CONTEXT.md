# Project Context — Food Delivery Platform

**Статус документа:** Living document  
**Последнее обновление:** 2026-09-04  
**Владелец:** Tech Lead / Software Architect  
**Аудитория:** вся команда разработки, Product Owner, новые участники, аудиторы

## 1. Бизнес-контекст

Мы разрабатываем **Food Delivery Platform** — микросервисную систему онлайн-заказа еды с доставкой.

Ключевые бизнес-возможности (high-level):
- Поиск и просмотр меню ресторанов
- Оформление заказа
- Оплата
- Отслеживание статуса заказа в реальном времени
- Управление доставкой
- Управление меню и наличием блюд ресторанами
- Административные функции

Платформа должна быть готова к росту нагрузки и добавлению новых возможностей (программы лояльности, рекомендации, курьерское приложение и т.д.).

## 2. Архитектурный подход

- **Стиль:** микросервисная архитектура
- **Репозитории:** multi-repo (один сервис = один репозиторий)
- **Коммуникация:**
  - Синхронная: REST (OpenAPI) + OpenFeign + Resilience4j
  - Асинхронная: Apache Kafka (основной брокер сообщений)
- **Данные:** каждый сервис владеет своей базой данных (Database per Service)
- **API:** API-first подход (OpenAPI-спецификации — источник истины)

## 5. Процесс разработки

- **Ветвление:** Git-flow с основными ветками `dev` → `test` → `prod`
- **Feature-ветки** ответвляются от `dev` и мержатся обратно в `dev` через Pull Request + Code Review
- **Бэклог и спринты:** Jira (Epic → Story → Sub-task)
- **Детальные описания User Stories и Acceptance Criteria:** Confluence
- **Архитектурные решения:** фиксируются в ADR (в этом репозитории)
- **Definition of Ready / Definition of Done:** обязательны для всех задач

## 6. Текущий статус (Sprint 0)

**Цель Sprint 0:** подготовить все необходимые процессные, документационные и инфраструктурные артефакты, чтобы команда могла начать Sprint 1.

Этапы Sprint 0:
1. Документация и процессные артефакты (текущий этап)
2. Настройка Jira + Confluence
3. Инфраструктурный репозиторий
4. Сервисные репозитории (шаблон + создание)
5. Минимальный CI
6. Чек-лист готовности + первый Sprint Planning
